# Contributing

## Prerequisites

- Node.js 18+
- [Freighter wallet](https://freighter.app) browser extension (for manual testing)

## Getting Started

```bash
cp .env.example .env
npm install
npm run dev
```

## How to Contribute

1. Find an issue labeled `good first issue`
2. Comment before starting
3. Fork, branch (`feat/my-feature`), implement, open a PR
4. Link the issue with `Closes #<number>`

## Code Style

```bash
npm run lint
```

Lint must pass before a PR is merged.
